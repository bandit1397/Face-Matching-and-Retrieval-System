# 발견 치매노인 얼굴 대조 프로그램

지구대 사무실 PC에서 쓰는 **오프라인 얼굴 대조 프로그램**입니다.
현장 경찰관이 보낸 사진을 넣으면, 미리 등록해 둔 사진 중 닮은 사람을 점수 순으로 보여줍니다.

- 무료 / 인터넷 연결 불필요 (사진이 외부로 전송되지 않음)
- 얼굴 인식 모델: InsightFace `buffalo_l` (ArcFace, 공개 모델 중 최상위급 정확도)
- 📄 사무실 게시용 안내문: [docs/얼굴대조_안내문.pdf](docs/얼굴대조_안내문.pdf) (A4 2장, 원본: `docs/안내문_원본.html`)

---

## 1. 설치 (사무실 PC, 최초 1회)

1. `dist\apps` 폴더 전체를 사무실 PC로 복사 (예: `C:\얼굴대조\`)
2. `apps.exe` 를 오른쪽 클릭 → **바탕화면에 바로가기 만들기**
3. 파이썬 설치는 필요 없습니다.

## 2. 사람 등록

`apps.exe` 옆의 `faces` 폴더 안에 **사람마다 폴더 하나**를 만들고 사진을 넣습니다.

```
faces\
  홍길동_1942\
    정면.jpg
    최근사진.jpg
    info.txt        ← (선택) 보호자 연락처·주소·특이사항
  김영희_1938\
    사진1.jpg
```

- 폴더 이름이 결과 화면에 표시됩니다 (한글 가능).
- **사진은 여러 장일수록 정확**합니다 (정면, 안경 쓴/벗은, 최근 사진 등 2~5장 권장).
- `info.txt` 예시:
  ```
  보호자: 아들 홍철수 010-1234-5678
  주소: ○○동 ○○아파트
  특이사항: 자주 ○○시장 방향으로 배회
  ```
- 추가·삭제 후 프로그램 화면의 **[DB 다시 읽기]** 버튼을 누르세요. (바뀐 사진만 계산하므로 빠름)

### 등록 확인

1. 화면 위쪽의 **"등록 인원 ○명 / 사진 ○장"** 숫자가 늘었는지 확인합니다.
2. 빨간 글씨로 **"얼굴 못 찾은 사진: 홍길동_1942/○○.jpg"**가 나오면, 그 사진을 더 선명한 정면 사진으로 바꾸고 다시 [DB 다시 읽기]를 누릅니다.
3. **(권장) 시험 대조**: 등록한 사진 중 한 장을 화면에 끌어다 놓아 보세요. 그 사람이 1등, 🟢높음으로 나오면 등록이 끝난 것입니다.

### 수정과 삭제

- **사진 추가나 교체**: 해당 사람 폴더에 사진을 넣거나 바꾼 뒤 [DB 다시 읽기]를 누릅니다.
- **찾은 뒤 삭제**: 사람 폴더를 통째로 지운 뒤 [DB 다시 읽기]를 누릅니다.
  - 얼굴 사진은 민감정보라서, 등록할 때 **보호자 동의**를 받고 더 필요 없으면 삭제하는 것이 좋습니다.

## 3. 현장 사진 대조

1. 현장 경찰관 → 사무실로 사진 전송 (폴리폰 메신저, 카카오톡 PC버전 등 평소 쓰는 방법)
2. `apps.exe` 실행 → 브라우저가 자동으로 열림 (검은 창은 닫지 마세요)
3. 사진을 넣는 방법 3가지 (편한 것 사용)
   - 메신저 PC 창에서 사진을 **화면으로 끌어다 놓기**
   - 사진 복사 후 화면에서 **Ctrl+V**
   - 클릭해서 파일 선택
4. 결과 확인

| 표시 | 점수 | 의미 |
|---|---|---|
| 🟢 높음 | 50 이상 | 동일인 가능성 높음 → 보호자 연락하여 확인 |
| 🟡 확인 필요 | 35~50 | 사진을 직접 비교하고 추가 확인 |
| ⚪ 낮음 | 35 미만 | 다른 사람일 가능성 높음 |

> ⚠ 결과는 **참고용**입니다. 최종 신원 확인은 반드시 보호자 확인, 지문 사전등록 조회 등으로 하세요.

### 현장 촬영 요령 (경찰관에게 안내)
- 얼굴이 화면의 1/3 이상 차도록 **가까이, 정면**에서
- 모자·마스크 벗기, 역광 피하기, 흔들리지 않게
- 대상자 혼자 나오게 (여러 명이면 가장 큰 얼굴로 대조함)
- 메신저로 보낼 때 가능하면 **원본 화질**로 전송

## 4. 개인정보 주의

- 얼굴 사진은 민감정보입니다. 보호자 동의를 받아 등록하고, 찾은 뒤에는 필요 없으면 삭제하세요.
- 현장 사진은 프로그램이 디스크에 저장하지 않습니다 (메모리에서만 처리).
- 프로그램은 이 PC 안에서만 접속됩니다 (`127.0.0.1`, 외부 접속 불가).
- `faces`, `data` 폴더는 GitHub 등 외부에 올리지 마세요 (`.gitignore`로 제외되어 있음).

## 5. 개발자용: 소스 실행 / exe 다시 만들기

```
pip install insightface onnxruntime flask opencv-python pillow pyinstaller
python apps.py
```

exe 빌드 (모델 파일 `det_10g.onnx`, `w600k_r50.onnx` 를 `models\models\buffalo_l\` 에 넣은 뒤):

```
python -m PyInstaller apps.spec --noconfirm --distpath out
```

빌드 결과 `out\apps\` 의 `apps.exe` 와 `_internal` 을 배포 폴더에 덮어쓰면 됩니다 (`faces` 폴더는 유지).

> InsightFace 사전학습 모델은 비상업적 용도로 공개되어 있습니다. 공공기관 내부 업무용으로 쓰되 판매·상용 서비스에는 사용하지 마세요.
