① 치매노인 사진 등록 절차

얼굴 대조 프로그램(apps.exe) — 새 대상자를 등록할 때 이 순서대로 하세요

1

사진 준비 (1명당 2~5장 권장)

  • 정면 사진(가장 중요), 최근 1년 이내 사진, 안경 쓴 사진·벗은 사진
  • 얼굴이 크고 선명하게 / 모자·마스크 없이 / 혼자 나온 사진 (단체 사진은 얼굴만 잘라서)
  • 보호자에게 카카오톡으로 받을 때는 원본 화질로 받기 · 등록 시 보호자 동의 받기
2

사람 폴더 만들기

  1. 프로그램 폴더 안의 faces 폴더 열기 (apps.exe 바로 옆에 있는 폴더)
  2. 빈 곳 오른쪽 클릭 → 새로 만들기 → 폴더
  3. 폴더 이름: 이름_출생연도 (예: 홍길동_1942) — 결과 화면에 이 이름이 표시됨
3

사진 넣기

만든 폴더 안에 사진 파일 복사 (파일 이름은 아무거나 가능, jpg·png)
faces └ 홍길동_1942 ├ 정면.jpg ├ 최근.jpg └ info.txt ← 보호자 정보 (4번)
※ 사진을 faces 폴더에 바로 넣으면 인식되지 않습니다. 반드시 사람 폴더 안에!
4

보호자 정보 적기 (권장)

같은 폴더에서 오른쪽 클릭 → 새로 만들기 → 텍스트 문서 → 이름을 info.txt로 바꾸고 작성·저장
보호자: 아들 홍철수 010-1234-5678 주소: ○○동 ○○아파트 101동 특이사항: 자주 ○○시장 방향으로 배회, 왼쪽 눈썹 위 점
→ 일치자가 나오면 결과 화면에 함께 표시되어 바로 연락 가능
5

프로그램에 반영

  • 프로그램이 켜져 있으면: 화면 위쪽 DB 다시 읽기 버튼 클릭
  • 프로그램이 꺼져 있으면: apps.exe 실행 → 자동 반영
6

등록 확인

  1. 화면 위쪽 "등록 인원 ○명 / 사진 ○장" 숫자가 늘었는지 확인
  2. 빨간 글씨 "얼굴 못 찾은 사진"이 나오면 → 더 선명한 정면 사진으로 교체 후 다시 DB 다시 읽기
  3. 시험 대조: 등록한 사진 1장을 화면에 끌어다 놓기 → 그 사람이 1등·높음이면 등록 완료

수정 · 삭제

  • 사진 추가·교체: 해당 사람 폴더에 사진을 넣거나 바꾼 뒤 DB 다시 읽기
  • 찾은 뒤 삭제: 사람 폴더를 통째로 삭제 후 DB 다시 읽기 (얼굴 사진은 민감정보 — 필요 없으면 삭제)

② 현장 사진 대조 절차

현장 경찰관이 보낸 발견 어르신 사진을 등록자와 대조할 때

1

현장 사진 받기

현장 경찰관 → 사무실로 사진 전송 (폴리폰 메신저, 카카오톡 PC버전 등 평소 쓰는 방법, 원본 화질)
2

프로그램 실행

바탕화면의 apps.exe 실행 → 약 10~20초 후 브라우저 화면이 자동으로 열림
※ 함께 뜨는 검은 창은 프로그램 본체입니다. 사용하는 동안 닫지 마세요 (최소화는 가능).
3

사진 넣기 (편한 방법 1가지)

  • 메신저 창의 사진을 프로그램 화면으로 끌어다 놓기
  • 사진을 복사한 뒤 프로그램 화면에서 Ctrl + V
  • 점선 상자를 클릭해서 파일 선택
4

결과 확인 (닮은 순서로 5명 표시)

표시점수조치
높음50 이상동일인 가능성 높음 → info.txt의 보호자에게 연락하여 확인
확인 필요35 ~ 50등록 사진을 클릭해 크게 보고 직접 비교 + 추가 확인
낮음35 미만다른 사람일 가능성 높음 → 아래 다른 확인 방법 진행
노란 경고(얼굴이 여러 명 / 작거나 흐림)가 나오면 → 현장에 재촬영 요청

현장 촬영 요령 (출동 경찰관 안내용)

  • 얼굴이 화면의 1/3 이상 차도록 가까이, 정면
  • 모자·마스크 벗기
  • 역광 피하기, 흔들리지 않게
  • 대상자 혼자 나오게 (옆사람 얼굴 X)
  • 여러 장 찍어 가장 선명한 것 전송
  • 메신저 전송 시 원본 화질

반드시 지킬 것

  • 결과는 참고용입니다. 최종 신원 확인은 보호자 확인 · 지문 사전등록(안전Dream) 조회 · 배회가능 어르신 인식표 번호 조회로 하세요.
  • 일치자가 없어도 등록되지 않은 사람일 수 있습니다 → 실종신고 조회, 지문 조회 등 기존 절차를 함께 진행하세요.
  • 프로그램은 인터넷 없이 이 PC 안에서만 작동하며 현장 사진은 저장되지 않습니다. 얼굴 사진을 외부로 반출하지 마세요.

문제가 생기면

  • 화면이 안 열림 → 브라우저 주소창에 127.0.0.1:5000 입력 / 그래도 안 되면 검은 창을 닫고 apps.exe 다시 실행
  • "얼굴을 찾지 못했습니다" → 얼굴이 크고 정면으로 나온 사진으로 다시 받기

1

[DB 다시 읽기]를 누르면 얼굴을 숫자로 바꿔 저장합니다

프로그램은 faces 폴더의 사진마다 다음을 합니다.
  1. 사진에서 얼굴 위치를 찾습니다 (얼굴 검출 AI)
  2. 찾은 얼굴을 숫자 512개로 바꿉니다 (얼굴 인식 AI)
    • 눈 사이 거리, 코·턱 모양 같은 얼굴 특징을 요약한 일종의 "얼굴 지문"입니다.
    • 같은 사람이면 사진이 달라도 비슷한 숫자가, 다른 사람이면 다른 숫자가 나오도록 수백만 장의 얼굴로 미리 학습된 AI입니다.
  3. 이 숫자들을 data\db.npz 파일에 저장해 둡니다.
2

현장 사진을 끌어다 놓으면 숫자끼리 비교합니다

  1. 현장 사진에서도 똑같이 얼굴을 찾아 숫자 512개로 바꿉니다.
  2. 저장해 둔 등록자 전원의 숫자와 얼마나 비슷한지 계산합니다 → 화면의 유사도 점수
  3. 점수가 높은 순서로 5명을 보여줍니다.

그래서 빠르고 안전합니다

  • 빠른 이유: 사진끼리 직접 비교하지 않고 미리 저장한 숫자끼리 계산합니다. 등록자가 수천 명이어도 1초 안팎에 끝납니다.
  • 비슷하지만 똑같지 않은 사진도 찾는 이유: 픽셀이 아니라 얼굴 특징을 비교합니다. 조명·옷·배경·표정이 달라도 같은 사람이면 점수가 높게 나옵니다. (시험 결과: 같은 사람 72~79점, 다른 사람 27점 이하)
  • 안전한 이유: 모든 과정이 사무실 PC 안에서만 일어납니다. 사진이 인터넷으로 나가지 않고, 현장 사진은 저장도 하지 않습니다.

같은 사람이어도 점수가 낮게 나올 수 있는 경우

  • 측면이나 고개를 숙인 사진
  • 너무 작거나 흐린 사진
  • 마스크나 모자를 쓴 사진
  • 등록 사진이 너무 오래된 경우
→ 등록 사진은 최근 정면 사진으로 여러 장, 현장에서는 가까이서 정면으로 찍어 달라고 안내하세요.
